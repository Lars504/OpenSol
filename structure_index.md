## open_sol/

- `__init__.py`: Open_sol - GPU 2D / 3D multiphysics (FDTD / FDFD electromagnetics, modes, heat, currents / electrostatics, semiconductors, mechanics, acoustics, fluid): ModelSpec -> validate -> build -> run_study
- `__main__.py`: Command line python -m open_sol describe | template | check | profile | run | show | selftest | mesh-study; every command leaves a file
- `api.py`: Headless interface for agents and scripts (no Qt): describe, template / load / save, check, run, selftest, Results. run and live Results use the GPU on the calling thread: never mix them with a GUI BackendWorker in one process.
- `simulation.py`: Simulation scripting API: a Domain with named physics solvers and couplings stepped by one MultiphysicsRunner (Simulation(size_x, size_y, dx) = the single 2D EM-FDTD convenience path).
